# SAE Graphes Python, mots, langages et automates finis

Projet de SAE, BUT Informatique 1re année, IUT de Marne-la-Vallée (2026).

Implémentation en Python des opérations de base sur les mots, les langages formels et les automates finis. Le sujet est fourni dans `sae.pdf`, le code dans `SAE math.py`.

## Contenu

**Mots et langages**
- préfixes, suffixes, facteurs, miroir d'un mot
- concaténation et puissance de langages
- génération de tous les mots d'une longueur donnée

**Automates finis**
- lecture d'un mot, test d'acceptation, langage accepté
- test de déterminisme et déterminisation
- automate complet, complétion, complément
- produit d'automates : intersection et différence
- clôtures : préfixe, suffixe, facteur, miroir

**Minimisation**
- calcul des classes d'équivalence par raffinements successifs, puis construction de l'automate minimal

## Lancer

```
python "SAE math.py"
```

Python 3, aucune bibliothèque externe.
